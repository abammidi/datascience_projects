# Labor Force Suitability - Predictive Analysis

Status: TBD

## Overview

This project uses the 2019 American Time Use Survey (ATUS) respondent data from the Bureau of Labor Statistics (BLS). It aims to identify underserved populations and help recruiters find viable candidates for labor opportunities by scoring non-skill behaviors from survey responses, using correlation and clustering approaches.
