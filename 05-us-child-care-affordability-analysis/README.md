# US Child Care Affordability Crisis Analysis

Status: Draft

## Overview

This project converts monthly child care cost figures into a 6-month mean cost and compares it across states and age groups. The goal is to show policymakers where child care is least affordable, so they can target subsidies to high-cost regions.
