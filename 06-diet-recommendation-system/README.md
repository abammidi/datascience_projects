# Diet Recommendation System

Status: In progress

## Overview

This project explores a recipe dataset and builds a recommendation application based on personal preferences. It helps users find food that fits their dietary needs, allergy restrictions, and food preferences, with healthier alternatives based on fitness and nutrition goals.
